# Calculadora Simples

Este repositório contém uma calculadora básica e um pequeno conjunto de testes em Node.js.

## Executando os testes

1. Instale as dependências (requer Node.js e npm):

   ```bash
   npm install
   ```

2. Rode os testes:

   ```bash
   npm test
   ```

Os testes usam `jsdom` e `assert` para carregar `javaloucura.js`, simular valores de entrada e verificar o resultado da função `calculate()`.
